OMEN 独立控制器 0.3.0 — HP 84DB / BIOS F.19
================================================

仅保留默认 0、性能 1、酷冷 2 三种原生 BIOS 模式。
Eco 已移除：它实际是 BIOS 默认模式 + 软件限帧、降刷新率和禁用睿频。
写接口仍是 HP WMI 0x20008 / 0x1A / FF <模式> 00 00。

EC 回读按本机 ACPI DSDT 实现：
NVPM=EC[0xF8] bit 1；COLM=EC[0xEC] bit 0。
0/0=默认，1/0=性能，0/1=酷冷，1/1=未知/冲突。
EC[0x95] 在本机是 MMST/DMST，不能套用新机型的 HPCM 映射。

保留 ec 和 driver 文件夹。已有驱动直接使用；缺失时点击“启用硬件读取（安装驱动）”，
使用随包官方签名 PawnIO 2.2.0 安装包完成一次安装，不需要另外下载。
程序请求管理员权限，不加载 OmenMon、Gaming Hub、WinRing0 或 PawnIOLib DLL。
读取协议与驱动调用由本项目自行实现；底层仍依赖签名驱动，不是无驱动方案。
仅点击启用/更新按钮才运行驱动安装包；启动和刷新不会安装，退出不会卸载共享驱动。
配置保存在程序旁 data 目录，首次导入旧语言与键盘预设。详见 docs/portable.md。

启动、刷新和切换后读取真实 EC 状态，不再用 last-mode.txt 回退。
界面已移除屏幕刷新率和读取时间显示。
BIOS 接受指令与 EC 确认实际状态分别处理，失败或超时显示未知。
不后台轮询；其他软件改变状态后请点击刷新。

旧 normal-*.txt 备份存在时显示单独的“恢复旧节能设置”。仅恢复有备份的原值，
失败保留备份。OmenNvApi.dll 仅用于旧 NVIDIA 设置恢复。
普通模式切换不修改刷新率、限帧或 CPU 睿频。键盘功能保持可用。

build.ps1 重建两个相同 EXE；tests/run.ps1 运行无硬件访问的单元测试。
协议依据与本机实测结果见 docs/hardware-findings.md。
