# OMEN Lite Control v0.3.0

本版将性能控制收敛为真实 BIOS 模式，增加 EC 硬件状态回读，并改进便携部署和交互响应。

## 更新内容

- 移除软件组合 Eco，保留默认、狂暴 / 性能、酷冷三种原生 BIOS 模式；不再联动修改 NVIDIA 限帧、屏幕刷新率或 CPU 睿频。
- 自行实现 EC 读取与 PawnIO 通信，按本机固件映射读取真实性能标志。BIOS 指令接受与 EC 确认分别提示，失败显示未知，不使用最后设置记录代替实际状态。
- 随包提供官方签名 PawnIO 2.2.0 安装组件：检测并复用已有驱动，仅点击按钮后安装或更新；不自动安装、不自动重启、不随程序退出卸载共享驱动。
- 新包不依赖 NVIDIA DLL、OmenMon 或 Gaming Hub；设置移至便携 `data` 目录，支持导入旧语言与预设。
- BIOS 请求与完整 EC 回读串行执行，成功或失败后至少间隔 1 秒；相关按钮防连点，不积累请求。
- 语言切换不再读取硬件；颜色、亮度和预设编辑始终可用。键盘应用删除两次多余读取，以“已写入色值”区分写入结果与实际回读。
- 去掉界面刷新率与读取时间，更新中英文截图、安装与使用文档。
- 保留四分区静态 RGB、亮度、8 个预设，以及有备份时的旧 Eco 恢复入口。

## 安装与升级

下载 **OMEN-Lite-Control-v0.3.0-portable.zip**，完整解压后以管理员身份运行 `OMEN-Lite-Control.exe`，保留 `ec`、`driver` 文件夹。真实性能回读需要 PawnIO；若未安装，点击“启用硬件读取（安装驱动）”完成一次准备。没有驱动仍可进行受支持的 BIOS 模式切换与键盘控制。

升级前关闭旧版，保留 `data`；需要恢复旧 Eco 时也保留原目录及 `normal-*.txt`，NVIDIA 限帧恢复另需旧版 `OmenNvApi.dll`。完整步骤与截图见 README。Source code 压缩包不包含编译后的主程序，请使用 portable ZIP。

## 支持与验证

- 性能模式控制和 EC 回读仅验证 **HP OMEN 15-dc0xxx / 主板 84DB / BIOS F.19**；其他映射被拒绝。
- EC 协议、解码、驱动状态/安装包完整性与请求互斥/间隔测试通过；本机模式切换回读、快速刷新和刷新中切换语言已验证。
- 新安装按钮尚未在无 PawnIO 的机器上完成端到端验证；相同官方安装包已在本机安装成功。
- 操作互斥只协调本程序，不能排除其他软件或固件同时访问 EC；读取失败请稍后重试。

校验下载内容可使用同页的 `SHA256SUMS.txt`。
